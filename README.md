## Cabin Voice (DATA-549 project app)

Interactive Streamlit app for the Twitter US Airline Sentiment project: score a tweet, batch scoring,
airline benchmark and comparison, complaint topics (NMF) and model performance.
Code is in [`cabin-voice/`](cabin-voice/). Run locally with `streamlit run cabin-voice/app.py`.
App code and styling were written with help from an AI assistant (Claude), cited per the course AI policy.
